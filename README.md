# Build an Atom: Discovering Atomic Number and Mass Number

An interactive lab for 10th-grade New York State Regents Chemistry (HS-PS1-1). Students build atoms, see how protons, neutrons, and electrons set an atom's identity, mass number, and charge, and practice the calculations until they can solve Regents-style problems on their own.

**Time:** 35–45 minutes · **Format:** one self-contained `index.html`, no install or sign-in.

## Modules

1. **Meet the subatomic particles:** clickable atom model, a drag-and-drop sorting activity, and a 3-question check.
2. **Build an atom:** add and remove particles. The element, symbol, atomic number, mass number, charge, isotope notation, and a periodic table highlight update live. Includes three guided investigations (changing protons, neutrons, and electrons).
3. **Atomic number and mass number:** each formula taught and practiced right away, with a formula panel students can hide.
4. **Challenge table:** a 10-row table with Check Row, progressive hints, four practice levels, and a mastery tracker.
5. **Atomic Detective:** five mystery-element cases plus unlimited random cases, with three-step hints and an animated reveal.
6. **Isotope notation:** decode symbols, build notation, and compare carbon-12, -13, and -14.

**Final assessment:** 15 questions (5 multiple choice, 5 calculations, 3 table rows, 2 isotope notation). Two versions, a score report, explanations, and retry of missed questions.

## Notes for teachers

- All isotopes in the activities and assessment are real; random problems use only stable isotopes.
- Common misconceptions (for example, counting electrons in the mass number) trigger targeted feedback.
- Progress is saved in the student's own browser only. Students can copy a text report from the final assessment.
- Works with keyboard and touch; animation can be turned off.

To use it, open `index.html` in a browser, or enable GitHub Pages for this repository.
