Build an Atom

Discovering atomic number and mass number

Learning goals

Essential question: How can atomic number and mass number be used to determine the composition and identity of an atom?

Today I will investigate how protons, neutrons, and electrons determine an atom’s atomic number, mass number, and identity.

So I can use atomic number and mass number to calculate the numbers of protons, neutrons, and electrons in atoms.

I am successful when I can:
  1. Identify the location and charge of protons, neutrons, and electrons.
  2. Explain that atomic number equals the number of protons.
  3. Explain that mass number equals protons + neutrons.
  4. Find the protons, electrons, and neutrons in a neutral atom.
  5. Calculate mass number from protons and neutrons.
  6. Calculate atomic number from particle information.
  7. Calculate neutrons from mass number and atomic number.
  8. Identify an element from its number of protons.
  9. Interpret isotope notation.
  10. Solve Regents-style questions with these relationships.

Standards: NYS P-12 Science Learning Standards, HS-PS1-1 (atomic structure and the periodic table).

Module 3

Discover atomic number and mass number

Learn each relationship, then use it right away.

Common mix-ups

“Atomic number is the total number of particles.” No. Atomic number counts protons only.

“Mass number includes electrons.” No. Mass number = protons + neutrons.

“Changing neutrons changes the element.” No. It changes the isotope. Only protons decide the element.

“Electrons always equal protons.” Only in neutral atoms. Ions have more or fewer electrons.

“The atomic mass on the periodic table is the mass number.” No. Mass number is a whole number for one isotope. The atomic mass (like 12.011 for carbon) is a weighted average of the naturally occurring isotopes.

“You can find neutrons from atomic number alone.” No. You also need the mass number.

Module 6

Isotope notation

Isotope notation packs the mass number, atomic number, and symbol into one compact label.

14Mass number (A), upper left: protons + neutrons
6Atomic number (Z), lower left: protons
CElement symbol: carbon

So carbon-14 has 6 protons, 6 electrons (neutral atom), and 14 − 6 = 8 neutrons.
